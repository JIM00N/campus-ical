학사일정 구독
소개업데이트 내역이용방법

이용 방법 & 자주 묻는 질문

대학 학사일정을 개인 캘린더 앱에서 자동으로 받아보는 방법과, 자주 묻는 질문을 정리했습니다. 기기별 단계별 구독 가이드도 함께 참고하세요.

📌 구독은 어떻게 하나요?
  1. 메인 화면에서 학교를 선택합니다.
  2. 받고 싶은 일정(전체 또는 카테고리)을 고르고 URL을 복사하거나, "캘린더 앱으로 바로 추가" 버튼을 누릅니다.
  3. 구글·애플·아웃룩 등 평소 쓰는 캘린더 앱에 구독 추가하면, 이후 학사일정이 자동으로 동기화됩니다.
🤖 안드로이드에서 구독 추가가 안 돼요가장 많이 묻는 질문

⚠️ 구글 캘린더 모바일 앱에서는 구독(URL) 추가 기능이 없습니다. 이건 구글의 제한이라 우회할 수 없습니다.

  1. 위 URL을 복사합니다.
  2. PC 또는 폰 브라우저로 calendar.google.com에 접속합니다.
  3. 왼쪽 "다른 캘린더" 옆 + → "URL로 만들기" → 복사한 URL 붙여넣기.
  4. 한 번 추가하면 폰의 구글 캘린더 앱에도 자동으로 나타납니다.
📱 삼성 캘린더에서 보려면?

위 방법대로 먼저 구글 캘린더에 추가한 뒤, 삼성 캘린더 앱의 설정 → 동기화할 캘린더(또는 표시할 캘린더)에서 해당 구글 캘린더를 켜주세요.

🍎 아이폰 · 맥에서는요?
  1. 아이폰/아이패드: "캘린더 앱으로 바로 추가" 버튼을 누르고 팝업에서 "구독"을 선택하면 끝입니다. 안 되면 설정 → 캘린더 → 계정 → 계정 추가 → 기타 → 구독 캘린더 추가.
  2. 맥(macOS 캘린더): 캘린더 앱 → 상단 메뉴 파일 → 새로운 구독 캘린더… → URL 붙여넣기.
🔄 일정은 언제 갱신되나요?

각 학교 공식 홈페이지에서 매일 자동으로 동기화합니다. 학교가 학사일정을 변경하면 보통 하루 안에 구독한 캘린더에도 반영됩니다. (캘린더 앱에 따라 반영까지 시간이 걸릴 수 있습니다.)

💸 무료인가요?

네, 완전 무료입니다. 회원가입도 필요 없습니다.

✅ 일정이 정확한가요?

각 대학의 공식 학사일정을 자동으로 수집합니다. 다만 자동 수집 특성상 오차가 있을 수 있으니, 시험·등록·졸업처럼 중요한 일정은 학교 공식 공지를 한 번 더 확인하시길 권합니다.

🏫 내 학교가 없어요

아직 일부 학교만 지원합니다. 학교 신청하기로 알려주시면, 신청이 많은 학교부터 추가합니다.

🔒 개인정보를 수집하나요?

회원가입과 로그인이 없으며, 이름·이메일 등 개인을 식별하는 정보를 수집하지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

학사일정은 각 학교 공식 사이트에서 매일 자동으로 동기화됩니다. 일정이 변경되면 캘린더에도 반영됩니다.
