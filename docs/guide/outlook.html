Outlook에서 구독하기

Outlook 웹(outlook.com 또는 회사·학교 계정의 outlook.office.com)에서 캘린더 주소를 구독할 수 있습니다.

단계별 방법

  1. 학교 페이지에서 URL 복사 버튼을 눌러 주소를 복사합니다.
  2. 브라우저로 Outlook 웹에 접속한 뒤 캘린더 화면으로 이동합니다.
  3. 왼쪽 사이드바에서 "캘린더 추가"를 누릅니다.
  4. "웹에서 구독"(Subscribe from web)을 선택합니다.
  5. 복사한 URL을 붙여넣고 이름을 정한 뒤 "가져오기"를 누릅니다.

추가하면 데스크톱 Outlook 앱과 모바일 Outlook 앱에도 같은 계정으로 동기화되어 나타납니다.

잘 안 될 때

  • "웹에서 구독" 메뉴가 안 보이면 데스크톱 앱이 아니라 Outlook 웹에서 시도하세요. 구독 추가는 웹에서 가장 안정적입니다.
  • 회사·학교 계정은 관리자 정책으로 외부 구독이 제한될 수 있습니다. 이 경우 개인 Outlook 계정이나 다른 캘린더 앱을 사용하세요.
  • Outlook의 외부 캘린더 갱신은 반영까지 시간이 걸릴 수 있습니다.

다른 플랫폼은 구독 가이드 홈에서 확인할 수 있습니다.

학사일정은 각 학교 공식 사이트에서 매일 자동으로 동기화됩니다. 일정이 변경되면 캘린더에도 반영됩니다.
