아이폰 · 아이패드에서 구독하기

아이폰과 아이패드는 별도 앱 없이 기본 캘린더 앱에서 바로 구독할 수 있어 가장 간단합니다.

방법 1 — "캘린더 앱으로 바로 추가" 버튼 (가장 쉬움)

  1. 메인 화면에서 학교를 선택합니다.
  2. "캘린더 앱으로 바로 추가" 버튼을 탭합니다.
  3. "이 캘린더를 구독하시겠습니까?" 팝업이 뜨면 "구독"을 선택합니다.
  4. 끝입니다. 기본 캘린더 앱에 학사일정이 나타나고, 이후 자동으로 갱신됩니다.

방법 2 — 설정 앱에서 직접 추가

버튼이 동작하지 않거나 주소를 직접 넣고 싶다면 아래 방법을 사용하세요.

  1. 학교 페이지에서 URL 복사 버튼을 눌러 주소를 복사합니다.
  2. 설정 앱 → 캘린더 → 계정 → 계정 추가로 이동합니다.
  3. 기타 → 구독 캘린더 추가를 선택합니다.
  4. 복사한 URL을 붙여넣고 다음 → 저장을 누릅니다.

잘 안 될 때

  • "구독" 대신 일반 일정으로 한 번만 추가되는 경우, 방법 2로 구독 캘린더 추가 메뉴를 사용하세요.
  • 일정이 보이지 않으면 캘린더 앱 하단의 "캘린더"에서 해당 구독 캘린더가 체크되어 있는지 확인합니다.
  • 갱신이 느리면 설정 → 캘린더 → 계정 → 가져오기(Fetch) 주기를 확인하세요. 앱 특성상 반영까지 시간이 걸릴 수 있습니다.

다른 기기에서 보기

같은 Apple ID를 쓰는 다른 기기(맥 포함)에서는 iCloud를 통해 자동으로 함께 나타납니다. 맥에서 직접 추가하려면 맥 캘린더 가이드를 참고하세요.

다른 플랫폼은 구독 가이드 홈에서 확인할 수 있습니다.

학사일정은 각 학교 공식 사이트에서 매일 자동으로 동기화됩니다. 일정이 변경되면 캘린더에도 반영됩니다.
