삼성 캘린더에서 구독하기

삼성(갤럭시) 캘린더는 구글 계정과 연동해서 사용합니다. 그래서 구글 캘린더에 먼저 추가한 뒤 표시만 켜면 됩니다.

1단계 — 구글 캘린더에 먼저 구독

삼성 캘린더 앱 자체에는 URL 구독 기능이 없습니다. 먼저 구글 캘린더 가이드를 따라 브라우저에서 학사일정 URL을 구글 캘린더에 추가하세요. (브라우저로 calendar.google.com → 다른 캘린더 + → URL로 만들기)

2단계 — 삼성 캘린더에서 표시 켜기

  1. 삼성 캘린더 앱을 엽니다.
  2. 왼쪽 위 ≡ 메뉴 → 설정(톱니바퀴) 또는 캘린더 관리로 이동합니다.
  3. 연동된 구글 계정 아래에서 방금 추가한 학사일정 캘린더를 찾습니다.
  4. 해당 캘린더의 표시(동기화)를 켭니다.

이제 삼성 캘린더에서 학사일정이 보이고, 학교가 일정을 바꾸면 자동으로 반영됩니다.

잘 안 될 때

  • 캘린더 목록에 안 보이면, 폰 설정 → 계정 → 구글 계정 → 동기화에서 캘린더 동기화가 켜져 있는지 확인합니다.
  • 구글 캘린더에서 외부 URL 구독은 반영까지 시간이 걸릴 수 있습니다. 잠시 후 다시 확인하세요.
  • 여러 구글 계정을 쓴다면, 캘린더를 추가한 계정과 삼성 캘린더에 연동된 계정이 같은지 확인하세요.

다른 플랫폼은 구독 가이드 홈에서 확인할 수 있습니다.

학사일정은 각 학교 공식 사이트에서 매일 자동으로 동기화됩니다. 일정이 변경되면 캘린더에도 반영됩니다.
