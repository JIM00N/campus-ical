대학 학사일정을 평소 쓰는 캘린더 앱에 한 번만 등록하면, 이후 일정이 자동으로 동기화됩니다. 사용하는 기기·앱에 맞는 가이드를 선택하세요.

먼저, 캘린더 주소(URL) 복사

  1. 메인 화면에서 학교를 선택합니다.
  2. 받고 싶은 일정(전체 또는 카테고리)을 고른 뒤 URL 복사 버튼을 누릅니다.
  3. 아래 플랫폼별 가이드를 따라 복사한 주소를 캘린더 앱에 등록합니다.

구독(URL 추가)과 일반 일정의 차이

이 서비스는 일정을 하나하나 복사해 넣는 방식이 아니라, 캘린더 주소(URL)를 구독하는 방식입니다. 그래서 학교가 일정을 바꾸면 내 캘린더에도 자동으로 반영됩니다. 단, 일부 앱은 "구독 캘린더"와 "일반 일정 추가" 메뉴가 다르니, 반드시 구독(URL로 추가) 메뉴를 사용해야 합니다.

자주 묻는 질문은 이용 방법 & FAQ에서 확인할 수 있습니다. 일정 데이터의 출처는 데이터 출처 페이지에 공개되어 있습니다.

학사일정은 각 학교 공식 사이트에서 매일 자동으로 동기화됩니다. 일정이 변경되면 캘린더에도 반영됩니다.
