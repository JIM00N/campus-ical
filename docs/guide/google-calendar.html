구글 캘린더(안드로이드)에서 구독하기

안드로이드 사용자가 가장 많이 막히는 부분입니다. 핵심만 알면 한 번에 됩니다.

⚠️ 구글 캘린더 모바일 앱에서는 URL 구독 추가 기능이 없습니다. 이는 구글의 제한이라 우회할 수 없습니다. 반드시 브라우저(PC 또는 폰)로 Google 캘린더 웹사이트에서 추가해야 하며, 한 번 추가하면 폰 앱에도 자동으로 나타납니다.

단계별 방법

  1. 학교 페이지에서 URL 복사 버튼을 눌러 캘린더 주소를 복사합니다.
  2. 브라우저로 calendar.google.com에 접속합니다. (PC가 가장 편하지만, 폰 브라우저에서 "데스크톱 사이트"로 접속해도 됩니다.)
  3. 왼쪽 사이드바의 "다른 캘린더" 옆 + 버튼을 누릅니다.
  4. "URL로 만들기"를 선택합니다.
  5. 복사한 URL을 붙여넣고 "캘린더 추가"를 누릅니다.
  6. 잠시 후 폰의 구글 캘린더 앱에서도 학사일정이 보입니다.

잘 안 될 때

  • 폰 앱에 바로 안 보이면, 앱 왼쪽 메뉴에서 해당 캘린더의 표시 체크를 켜주세요.
  • 폰 브라우저에서 + 버튼이 안 보이면, 브라우저 메뉴에서 "데스크톱 사이트"를 켠 뒤 다시 시도합니다.
  • 구글 캘린더의 외부 URL 구독은 반영까지 수 시간~하루가 걸릴 수 있습니다. 이는 구글의 갱신 주기 때문입니다.

삼성 캘린더를 쓴다면

삼성 캘린더는 구글 계정과 연동되므로, 위 방법으로 구글 캘린더에 먼저 추가한 뒤 삼성 캘린더에서 표시만 켜면 됩니다. 자세한 내용은 삼성 캘린더 가이드를 참고하세요.

다른 플랫폼은 구독 가이드 홈에서 확인할 수 있습니다.

학사일정은 각 학교 공식 사이트에서 매일 자동으로 동기화됩니다. 일정이 변경되면 캘린더에도 반영됩니다.
